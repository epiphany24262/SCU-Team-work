# 健身房管理系统 (Gym Management System)

这是一个基于 Spring Boot 的健身房管理系统，用于管理健身房的日常运营。

## 快速开始 (Quick Start)

### 构建项目 (Build)
```bash
./mvnw clean install
```

### 运行项目 (Run)
```bash
./mvnw spring-boot:run
```

### 访问应用 (Access)
```
http://localhost:8080
```

## 技术栈 (Tech Stack)
- Spring Boot 2.7.12
- Java 1.8
- MySQL 8.0.33
- Thymeleaf
- Spring JDBC

## 主要功能 (Main Features)
- 用户管理 (User Management)
- 教练管理 (Coach Management)
- 课程管理 (Course Management)
- 器材管理与预约 (Equipment Management & Reservation)
- 排课管理 (Schedule Management)
- 会员卡与VIP管理 (Membership Card & VIP Management)
